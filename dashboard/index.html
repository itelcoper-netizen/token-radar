How the implied value is built

Implied values are this board’s own claim, worked out from the snapshot’s figures alone — TVL, seven-day growth, how long the protocol has run with no token, and whether a token launch is plausible for its kind. They are not a prediction of whether or when a token is issued. A protocol is listed as pre-token because its DefiLlama record carries no token; that record is not proof that no token exists.
